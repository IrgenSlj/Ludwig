# Error catalogue

Errors seen in practice between the architect's documents and production (PLAN 0.5).
No company names, project names or real files. Phase 0 gate: at least 10 entries marked
`files` or `erp`.

Fields per entry:

- **What went wrong** — one or two sentences.
- **Truth held in** — the document that was right (model, schedule, drawing, spec text, …).
- **Would have shown it** — the data and the comparison that would have caught it.
- **Rough cost** — remake, delay, site fix; an order of magnitude is enough.
- **Catchable** — `files` (architect documents alone), `erp` (needs the production
  export), or `no` (PLAN 0.6).
